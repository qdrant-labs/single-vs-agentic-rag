Question: I forward web traffic through a router to an internal server, but once I apply an outbound filter on the router interface, external clients' HTTPS requests get no response. Why?
Reference answer: The server's reply is sent to the client's random source port, which the outbound access-list doesn't permit, so the router drops it.
