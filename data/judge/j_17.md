Question: In bash, how can I make .* match all hidden files except . and .., and what exactly does the glob .??* match?
Reference answer: Set GLOBIGNORE=".:.." and unset dotglob with shopt -u dotglob; .??* matches a literal dot, any two characters, then zero or more non-slash characters, so at least three characters.
Reference evidence:
[chunk 280911] how to glob every hidden file except current and parent directory
You can use the GLOBIGNORE variable to hide the . and .. directories. This does automatically also set the dotglob option, so * now matches both hidden and non-hidden files. You can again manually unset dotglob, though, this then gives the behavior you want.
See this example:
$ ls -a
. .. a .a ..a
$ GLOBIGNORE=".:.."
$ shopt -u dotglob
$ echo * # all (only non-hidden)
a
$ echo .* # all (only hidden)
.a ..a
Note the following corner cases shown by numerous users in the comments:
[chunk 302987] What does .??* mean in a shell command?
The .??* is a glob. It matches any file name that begins with a literal dot ., followed by any two (not necessarily the same) characters, ??, followed by the regular expression equivalent of [^/]*, i.e. 0 or more characters that are not /.
For the full details of shell pathname expansion (the full name for "globbing"), see the POSIX spec.
